# 🤖 AI Agents 学习仓库

> 一名大二 CS 学生的 AI Agent 学习记录 —— 16 周从零到独立开发

## 📋 学习计划总览

**目标：** 独立从零构建、部署生产级 AI Agent，积累可写进简历的作品集
**节奏：** 每周 8-10 小时（2h 理论 + 6h 动手 + 复盘）
**原则：** 先造轮子，再用框架

## 📁 目录结构

| 目录 | 对应阶段 | 内容 |
|------|---------|------|
| `week01-basics/` | 第 1 周 | 概念入门：读书笔记、Agent 循环图解 |
| `week02-tool-use/` | 第 2 周 | Function Calling / Tool Use 练习 |
| `week03-agent-loop/` | 第 3 周 | ⭐ 纯手写 Agent Loop（不用框架） |
| `week04-memory/` | 第 4 周 | 记忆机制：上下文管理 + 长期记忆 |
| `week05-06-rag/` | 第 5-6 周 | RAG：Embedding + 向量数据库 |
| `week07-mcp/` | 第 7 周 | MCP Server 实战 |
| `week08-framework/` | 第 8 周 | 主流框架（Claude Agent SDK / LangGraph） |
| `notes/` | 全程 | 学习笔记、论文阅读记录 |
| `projects/` | 第 9-13 周 | 作品集项目 |

## 🗺 路线图

- [ ] **Week 1** — 精读 Anthropic《Building Effective Agents》+ OpenAI Agent 指南
- [ ] **Week 2** — Claude API Tool Use：天气 + 计算器助手
- [ ] **Week 3** — 手写 Agent Loop：文件整理 Agent
- [ ] **Week 4** — 长期记忆（SQLite/JSON 存储）
- [ ] **Week 5-6** — RAG 知识问答（课程笔记喂给 Agent）
